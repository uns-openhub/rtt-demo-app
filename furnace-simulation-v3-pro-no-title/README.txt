Furnace Simulation - Linux Delivery
====================================

Install:
  1. Open a terminal in this folder.
  2. Run: ./Furnace-Simulation-Linux-Installer.run
  3. Follow the installer prompts.

Run without installing:
  1. Open the Furnace-Simulation folder.
  2. Run: ./furnace-simulation-v3

The application requires Python 3, GTK3/PyGObject, Podman, and Podman Compose.
The installer installs the required Linux packages on supported Debian/Ubuntu systems.

Local credentials are intentionally not included. Configure OpenHub login on first launch.
